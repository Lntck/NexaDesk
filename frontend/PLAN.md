## План фронтенда NexaDesk

План веб-клиента (React + Vite + TypeScript) на готовом API Phase 0-4.
Внешний вид задаёт style.json (Dark Liquid Glass) как ориентир. Он не является
источником правды: значения переносятся в токены CSS и дополняются по мере
нужды.

## Рамки MVP

- авторизация: регистрация, вход, refresh-cookie, выход
- проекты: список, создание, архивация и восстановление, участники и роли
- канбан-доска с drag and drop и командой reorder
- задачи: список с фильтрами, карточка задачи, назначение, статусы, приоритеты,
  дедлайн, оценка часов
- комментарии с упоминаниями, метки, вотчеры
- уведомления: колокольчик, drawer, read/unread, тосты
- live-обновления по SSE: один стрим на проект, replay по Last-Event-ID
- лента активности проекта и задачи

Вне MVP: доработки бэкенда (моя работа /me/tasks, глобальный поиск, связи задач,
настройки уведомлений, аватары и вложения). Зависимые от них пункты интерфейса
скрываются или показывают заглушки.

## Стек

- Vite, React, TypeScript, React Router
- TanStack Query для серверных кешей, Zustand для UI-состояния
- Lucide React для иконок, Inter как шрифт (оба названы в style.json)
- framer-motion для анимаций и FLIP, dnd-kit для drag and drop на доске
- CSS-переменные (tokens.css) + CSS Modules для стилизации
- Типы API генерируются из /openapi.json, чтобы клиент жил по контракту
  docs/api-endpoints.md

## Дизайн-система

style.json описывает вид (Dark Liquid Glass). Реализация:

- tokens.css: цвета, радиусы, тени, шкала шрифтов, spacing, motion. Значения
  из style.json плюс дополнения:
  - семантические цвета success, warning, danger, info
  - цвета приоритетов LOW, MEDIUM, HIGH, CRITICAL и статусов доски
  - шкала шрифтов 12/13/14/16/20/24/32 с line-height, шрифт Inter
  - радиусы 8/12/16/24/999 (в style.json указаны диапазоны, для токенов нужны
    фиксированные ступени)
  - spacing 4/8/12/16/24/32/48
  - тени и глубина три уровня, шкала z-index
  - motion: длительности 120/200/320 мс, кривые standard (0.2, 0.8, 0.2, 1) и
    exit (0.4, 0, 1, 1)
- контраст: text_muted #6F7785 держит 4.47:1, это ниже AA для мелкого текста.
  Поднять до #7B8391 или ограничить крупными подписями и плейсхолдерами
- блюр: тяжёлый backdrop-blur 20-30px только на модалках, drawer, сайдбаре,
  топбаре. Карточки доски и списки: полупрозрачность и граница без блюра,
  иначе сотня карточек убьёт fps
- ui-kit: Button, Input, Textarea, Select, Badge, Avatar, Card, Panel, Modal,
  Drawer, Tooltip, Toast, Tabs, Dropdown, EmptyState, Skeleton, Spinner
- состояния focus-visible для клавиатуры, prefers-reduced-motion отключает
  анимации

## Экраны и роуты

- /login, /register. Центральная glass-карточка. Ошибки 401, 422, 429
  показываются текстом из detail.
- /projects. Список проектов, создание, архивация и восстановление, передача
  владения.
- /projects/:id/board. Канбан: колонки из статусов, карточки, drag and drop с
  reorder, счётчики в колонках, optimistic-обновления.
- /projects/:id/tasks. Список с фильтрами: статус, приоритет, исполнитель,
  метка, текст названия.
- /projects/:id/activity. Лента активности с live-обновлениями.
- /projects/:id/members. Участники, роли, добавление и удаление.
- /projects/:id/labels, /projects/:id/settings. Метки проекта, статусы доски,
  метаданные проекта.
- /tasks/:id. Карточка задачи отдельным роутом, ссылку можно шарить; на доске
  открывается drawer поверх. Состав: ключ и заголовок, статус, приоритет,
  исполнитель, дедлайн, оценка часов, описание, метки, вотчеры, подзадачи,
  комментарии с упоминаниями, история.
- /me. Профиль, смена пароля, выход.
- Уведомления. Колокольчик в топбаре с бейджем непрочитанных и drawer со
  списком: фильтр read/unread, отметить все прочитанными, клик ведёт к задаче.
- Топбар: переключатель проектов, колокольчик, меню пользователя. Пункт поиска
  скрыт до появления API.

## Анимации

- Экраны: fade и сдвиг 8px, 200 мс.
- Модалки и drawer: затемнение 200 мс, панель scale 0.98 в 1 плюс fade;
  закрытие в обратную сторону.
- Списки (уведомления, комментарии): вход элемента fade и сдвиг 12px, удаление
  fade, optimistic-вставка сразу.
- Доска: подъём карточки scale 1.02 и тень, drop settle 200 мс, FLIP-сдвиг
  соседних карточек 150-200 мс.
- Тосты уведомлений: slide-in сверху справа 200 мс, авто-dismiss 5 с, стек до
  четырёх штук.
- Hover, active, focus: brightness, glass highlight, soft glow из style.json,
  через токены.
- Скелетоны с медленным shimmer только на загрузке.
- prefers-reduced-motion: анимации сводятся к fade или отключаются.

## Реалтайм и данные

- Один SSE-клиент на пару клиент-проект, авторизация заголовком, id последнего
  кадра в Last-Event-ID, авто-reconnect с бэкоффом.
- События обновляют кеши TanStack Query: task.updated, comment.created,
  member.added и остальные из раздела 22 контракта.
- notification.created приходит только адресату: инкремент бейджа, тост,
  обновление drawer.
- После reconnect уведомления ресинхронизируются через GET /notifications:
  read-состояние по SSE не транслируется.
- Конфликт stale_version (If-Match) показывается диалогом: задача изменена,
  обновить или перезаписать.

## Качество

- В CI: ESLint, Prettier, tsc --noEmit, сборка.

## Этапы

- M0 инфраструктура: Vite, роутинг, tokens.css, ui-kit, API-клиент с типами,
  auth-флоу, layout с топбаром и сайдбаром.
- M1 проекты: список, создание, участники, роли, статусы.
- M2 задачи и доска: drag and drop, фильтры, карточка задачи, диалог конфликта
  версий.
- M3 коллаборация: комментарии, упоминания с автокомплитом, метки, вотчеры.
- M4 уведомления и live: колокольчик, drawer, тосты, SSE.
- M5 полировка: активность, адаптив, a11y.

Готовность MVP: сценарии A-E из раздела 29 контракта проходятся в UI, ошибки из
раздела 4 показываются понятно, сборка зелёная.
